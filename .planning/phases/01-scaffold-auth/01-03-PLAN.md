<trex_manifest_schema>
The Tableau Extensions manifest is XML conforming to the Tableau-published schema at `http://www.tableau.com/xml/extension_manifest`. The minimum required elements for a valid stub are:

- `<manifest>` root with `manifest-version="0.1"` and xmlns
- `<dashboard-extension>` (for dashboard extensions — Aperture is a dashboard extension per CLAUDE.md)
  - `id` attribute = `com.aperture.copilot`
  - `extension-version` attribute
- `<default-locale>` child
- `<name resource-id="name"/>`
- `<description>`
- `<author name="..." email="..." organization="..." website="..."/>`
- `<min-api-version>1.4</min-api-version>` (full data support)
- `<source-location>` with `<url>` — points at the dev server URL in dev (http://localhost:5173/)
- `<icon>` (can be empty/placeholder in stub)
- `<permissions><permission>full data</permission></permissions>` — REQUIRED per CLAUDE.md
- `<resources><resource id="name"><text locale="en_US">Aperture Copilot</text></resource></resources>`

Example source reference (do NOT hallucinate — this is standard Tableau Extensions SDK stub shape; Phase 4 will refine).
