<objective>
Build the Pulse REST service: accept a datasource LUID, fan out to three Pulse
REST endpoints (metric definitions, insight bundles, feedback), and merge the
results into a typed `PulseContext`. When the datasource has no Pulse metrics
the service MUST return an empty-but-valid PulseContext with `hasMetrics: false`
— it MUST NOT throw. This is a CLAUDE.md hard ground rule ("degrade gracefully
if any Tableau API returns empty — never crash the panel") and gates every
downstream phase.

Purpose: Unlock TAPI-07, TAPI-08, TAPI-09, TAPI-10 and give Phase 3's Context
Assembler the Pulse insight half of its fan-out.

- `backend/src/services/__tests__/pulseService.empty.test.ts` (offline TAPI-10 unit test)

Tableau Pulse REST API endpoints (from the public Pulse API surface, Tableau Cloud 2024+):
- GET `{serverUrl}/api/-/pulse/definitions?datasource_luid=<LUID>`
  → { definitions: PulseMetricDefinition[] }
- POST `{serverUrl}/api/-/pulse/insights:generate`
  body: { metricId, time_range?, ... }
  → { bundles: PulseInsightBundle[] }
- GET `{serverUrl}/api/-/pulse/user/preferences` (feedback metadata)
  → { insight_feedback: Array<{ insight_type, thumbs_up, thumbs_down }> }

CLAUDE.md HARD ground rules:
- "Degrade gracefully if any Tableau API returns empty — never crash the panel"
- All three APIs share one X-Tableau-Auth token — tableauFetch owns it

The service's TAPI-10 graceful-degradation contract MUST hold regardless: a 404
on the definitions endpoint → return empty PulseContext with hasMetrics=false,

       ```typescript
       const defsUrl = `${base}/api/-/pulse/definitions?datasource_luid=${encodeURIComponent(datasourceLuid)}`;
       const defsRes = await tableauFetch(defsUrl, {
         method: 'GET',
         headers: { 'Accept': 'application/json' },
       });
       if (defsRes.status === 404 || defsRes.status === 403) {
         // TAPI-10: degrade gracefully. Some tenants disable Pulse entirely.
         log.info({ datasourceLuid, status: defsRes.status }, 'Pulse definitions unavailable — returning empty PulseContext');
         try { await defsRes.body?.cancel(); } catch { /* best-effort */ }
         return emptyPulseContext(datasourceLuid);
       }
       if (!defsRes.ok) {
         const text = (await defsRes.text()).slice(0, 500);
         throw new PulseServiceError(`Pulse definitions HTTP ${defsRes.status}: ${text}`);
       }
       const defsJson = (await defsRes.json()) as { definitions?: Array<{ id: string; name: string; description?: string }> };
       const metricDefinitions: PulseMetricDefinition[] = (defsJson.definitions ?? []).map(d => ({
         id: d.id,
         name: d.name,
         description: d.description ?? '',
         datasourceLuid,
       }));

       if (metricDefinitions.length === 0) {
         // TAPI-10: hard ground rule — datasource has no Pulse metrics. Return
         // a valid empty PulseContext. Do NOT throw. Do NOT hit the other
         // endpoints (no metrics means nothing to generate insights for).
         log.info({ datasourceLuid }, 'Datasource has no Pulse metrics — returning empty PulseContext (TAPI-10)');
         return emptyPulseContext(datasourceLuid);
       }
       ```

    5. **Step B — fetch insight bundles per metric** (TAPI-08):
       Run in parallel via `Promise.allSettled` — a failure on one metric's
       bundle must not take down the whole PulseContext (graceful degradation).
       ```typescript
       const bundleResults = await Promise.allSettled(
         metricDefinitions.map(async (m): Promise<PulseInsightBundle[]> => {
           const url = `${base}/api/-/pulse/insights:generate`;
           const res = await tableauFetch(url, {
             method: 'POST',
             headers: { 'Content-Type': 'application/json', 'Accept': 'application/json' },
             body: JSON.stringify({ metric_id: m.id }),
           });
           if (!res.ok) {
             try { await res.body?.cancel(); } catch { /* best-effort */ }
             return [];
           }
           const json = (await res.json()) as { bundles?: Array<{ id: string; insight_types?: string[]; summary?: string }> };
           return (json.bundles ?? []).map(b => ({
             metricId: m.id,
             bundleId: b.id,
             insightTypes: b.insight_types ?? [],
             summary: b.summary ?? '',
           }));
         }),
       );
       const insightBundles: PulseInsightBundle[] = bundleResults.flatMap(r =>
         r.status === 'fulfilled' ? r.value : [],
       );
       ```

       ```typescript
       let feedback: InsightFeedbackMetadata[] = [];

         const fbUrl = `${base}/api/-/pulse/user/preferences`;
         const fbRes = await tableauFetch(fbUrl, { method: 'GET', headers: { 'Accept': 'application/json' } });
         if (fbRes.ok) {
           const fbJson = (await fbRes.json()) as { insight_feedback?: Array<{ insight_type: string; thumbs_up?: number; thumbs_down?: number }> };
           feedback = (fbJson.insight_feedback ?? []).map(f => ({

             thumbsUp: f.thumbs_up ?? 0,
             thumbsDown: f.thumbs_down ?? 0,
           }));

         }
       } catch (err) {
       ```
