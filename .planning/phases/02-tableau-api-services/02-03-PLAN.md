<objective>
Build the VizQL Data Service: query published Tableau datasources via the VDS
query-datasource endpoint with field selection, filters, and a 500-row cap.
Every request MUST set `interpretFieldCaptionsAsFieldNames: true` (TAPI-04 — the
whole reason is so Claude sees the same field names the user sees). Attempt SSE
streaming first, fall back to JSON if SSE is unavailable (TAPI-05). Return a
typed `LiveDataContext` and record which transport was actually used.

Purpose: Unlock TAPI-03, TAPI-04, TAPI-05 and give Phase 3's Context Assembler
the live-data half of its fan-out.

```typescript
  readonly filterType: 'SET' | 'QUANTITATIVE_DATE' | 'QUANTITATIVE_NUMERICAL' | 'MATCH' | 'TOP';

}

  readonly datasourceLuid: string;
  readonly fields: readonly string[];
  readonly filters: readonly VizqlFilter[];
  readonly rows: ReadonlyArray<Readonly<Record<string, unknown>>>;
  readonly transport: 'sse' | 'json';
  readonly totalRows?: number;
}
```

Tableau VizQL Data Service endpoints (Tableau Cloud 2024.2+):
- JSON query: POST `{serverUrl}/api/v1/vizql-data-service/query-datasource`
- SSE stream: the actual streaming query endpoint (2026.1+) is the same path with
  header `Accept: text/event-stream` — servers that do not support streaming
  respond with a non-2xx (typically 406 Not Acceptable) or silently return
  application/json. The service MUST treat "response Content-Type is not
  text/event-stream" OR "status is 4xx other than 401" as the signal to fall
  back to JSON.

Request body shape (both transports):
```json
{
  "datasource": { "datasourceLuid": "<LUID>" },
  "options": { "returnFormat": "OBJECTS", "debug": false, "disaggregate": false },
  "query": {
    "fields": [ { "fieldCaption": "Sales", "function": "SUM" }, { "fieldCaption": "Region" } ],
    "filters": [ /* ... shaped per VizqlFilter */ ]
  },
  "interpretFieldCaptionsAsFieldNames": true
}
```

CLAUDE.md HARD invariants this service must honor:
- `interpretFieldCaptionsAsFieldNames: true` on every request (TAPI-04)
- max 500 rows (TAPI-03)
- All three APIs share one X-Tableau-Auth — do NOT set it yourself; tableauFetch owns it
- Degrade gracefully — never crash the panel

       ```typescript
       async function readSseRows(
         body: ReadableStream<Uint8Array>,
         limit: number,
       ): Promise<Array<Record<string, unknown>>> {
         const reader = body.getReader();
         const decoder = new TextDecoder();
         const rows: Array<Record<string, unknown>> = [];
         let buffer = '';
         while (rows.length < limit) {
           const { value, done } = await reader.read();
           if (done) break;
           buffer += decoder.decode(value, { stream: true });
           let nl: number;
           while ((nl = buffer.indexOf('\n\n')) !== -1) {
             const evt = buffer.slice(0, nl);
             buffer = buffer.slice(nl + 2);
             for (const line of evt.split('\n')) {
               if (!line.startsWith('data:')) continue;
               const payload = line.slice(5).trim();
               if (payload === '' || payload === '[DONE]') continue;
               try {
                 const parsed = JSON.parse(payload) as unknown;
                 if (Array.isArray(parsed)) {
                   for (const r of parsed as Array<Record<string, unknown>>) {
                     if (rows.length >= limit) break;
                     rows.push(r);
                   }
                 } else if (parsed && typeof parsed === 'object') {
                   const obj = parsed as { rows?: Array<Record<string, unknown>> };
                   if (Array.isArray(obj.rows)) {
                     for (const r of obj.rows) {
                       if (rows.length >= limit) break;
                       rows.push(r);
                     }
                   } else {
                     rows.push(parsed as Record<string, unknown>);
                   }
                 }
               } catch {
                 // Skip un-parseable SSE lines defensively; never crash the stream.
               }
             }
             if (rows.length >= limit) break;
           }
         }
         try { await reader.cancel(); } catch { /* best-effort */ }
         return rows;
       }
       ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| backend → VizQL Data Service | Caller-supplied datasource LUID + field captions + filters get embedded in request body and URL path. Untrusted input crosses here. |
| backend ← VizQL Data Service | Response rows can be large — need hard row cap to prevent memory exhaustion. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03-01 | Information disclosure (I) | Session token in logs | mitigate | Service uses `tableauFetch`. Pino redact paths from Phase 1 cover X-Tableau-Auth. No info-level logging of the Authorization header or raw response body in this plan. |
| T-02-03-02 | Spoofing (S) / SSRF | User-controlled datasource LUID concatenated into URL or body | mitigate | LUID is validated against `^[a-f0-9-]{36}$` before any use. The endpoint URL is a fixed constant string; the LUID only appears inside the JSON request body's `datasource.datasourceLuid` field — not in the URL path. |
| T-02-03-03 | Denial of service (D) | Unbounded response size from VDS | mitigate | `VIZQL_MAX_ROWS = 500` constant enforced twice: once in `effectiveLimit = Math.min(req.limit ?? MAX, MAX)` pre-request, and again via slice/early-break in both the SSE reader and the JSON parser. Acceptance criterion grep-verifies the literal. |
| T-02-03-04 | Tampering (T) | Filter injection via user-controlled filter values | mitigate | Filters are passed as structured JSON values inside the POST body, not interpolated into URL or query strings. VDS validates filter shape server-side. The service only accepts the typed `VizqlFilter` union. |
| T-02-03-05 | Information disclosure (I) | Query result PII in logs | mitigate | The smoke script prints only `firstRow` + row count + transport. Production code paths log `{ datasourceLuid, rowCount, transport }` — never the full rows array at info level. Redacted in writing patterns in Task 1 action. |

No high-severity unmitigated threats.
</threat_model>
